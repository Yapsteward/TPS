## 🛠️ Tech Stack & Architecture

- **Semantic Frontend**: Pure HTML5, Vanilla CSS3 (Custom Design System with tokenized CSS variables, Glassmorphism, and responsive fluid clamping).
- **Interactive Scripting**: Vanilla JavaScript with hysteresis-aware `IntersectionObserver` scroll triggers (glitch-free top and bottom boundary detection).
- **Animations & Effects**: Hardware-accelerated CSS keyframe continuous marquee tickers, pure CSS 3-slide auto-carousels, and dual-layer avatar hover portrait transitions.
- **Search Engine Optimization**: Complete Open Graph (`og:*`), Twitter Cards (`twitter:*`), Schema.org JSON-LD structured data, XML Sitemaps, and robots directives.

## 🌐 GitHub Pages Deployment Guide

To deploy this project directly to **GitHub Pages**:

1. **Push Repository to GitHub**:
   ```bash
   git init
   git add .
   git commit -m "feat: complete Tech Partners System portal with SEO and favicon"
   git branch -M main
   git remote add origin https://github.com/<YOUR-USERNAME>/<YOUR-REPO-NAME>.git
   git push -u origin main
   ```

2. **Enable GitHub Pages**:
   - Go to your repository on GitHub.
   - Click **Settings** → **Pages** (under the "Code and automation" section).
   - Under **Build and deployment** → **Source**, select **Deploy from a branch**.
   - Under **Branch**, select `main` and root `/ (root)`.
   - Click **Save**.

3. **Custom Domain (Optional)**:
   - Under **Custom domain**, enter `techpartnerssystems.com` (or your subdomain).
   - Check **Enforce HTTPS**.

## 🔍 Google Search Console Integration

1. Go to [Google Search Console](https://search.google.com/search-console).
2. Add your property (e.g. `https://techpartnerssystems.com` or your GitHub Pages URL).
3. Select **HTML tag** verification method.
4. Copy the verification code and paste it into line 27 of `index.html`:
   ```html
   <meta name="google-site-verification" content="YOUR_ACTUAL_CODE_HERE">
   ```
5. Navigate to **Sitemaps** on the left menu, submit `sitemap.xml`, and verify status reports green.
